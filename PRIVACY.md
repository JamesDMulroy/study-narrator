# Privacy

Study Narrator stores data only in this browser's extension storage:

- Settings.
- API keys, kept apart from settings.
- Your notes.
- Up to 300 question-and-answer entries, with page titles and URLs. Use **Clear history** in the panel's Chat tab to remove this history.
- Narration scripts for the last 20 pages.
- Page text for open tabs only, stored per tab.

The page text and your question go only to the backend you choose:

- **API backends:** the provider's API.
- **Claude Code or Codex:** your command-line tool, which sends requests to Anthropic or OpenAI.
- **ChatGPT web:** chatgpt.com.
- **Discuss in:** the title, URL and up to 6,000 characters are placed in the new tab's URL.

The native host log contains metadata only. There is no telemetry or analytics, and Study Narrator has no server of its own.
